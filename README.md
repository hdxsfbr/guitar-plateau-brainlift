# Guitar Plateau BrainLift

BrainLift (Gauntlet education assignment) on an integrated, adaptive guitar and musicianship tutor for adult intermediate guitarists who have plateaued and commit about two hours a day for two years.

## Status

Research phase. The assignment and prior Elicit exports are in `sources/`; read `CODEX_HANDOFF.md` first. Prior AI findings and candidate POVs are provisional leads, not conclusions.

## Key files

- `CODEX_HANDOFF.md`: scope decisions, assignment requirements, research questions, source leads, evidence rules
- `sources/assignment-brainlift-education.pdf`: authoritative assignment
- `sources/elicit-*`: raw Elicit exports (brief, citation audit, 31-record source CSV, UTF-8 with BOM); keep unmodified, put corrections in derived files
