# Guitar Plateau BrainLift

Structured BrainLift + Spiky POV project for intermediate / mid-advanced guitarists stuck on a multi-year plateau who want a serious path toward pro-level playing.

## Status

Scaffold only. Waiting on the official Gauntlet PRD before research and knowledge-tree work starts.

## Intended scope (draft)

- **Audience:** intermediate → mid-advanced guitar players on a long plateau
- **Outcome:** a maintained BrainLift (purpose, experts, knowledge tree, Spiky POVs) that can drive a practice program
- **Not yet decided:** exact genre focus, measurement metrics, expert shortlist

## Planned workflow (once PRD lands)

1. Lock purpose, outcome, and boundaries
2. Map consensus advice in guitar pedagogy / deliberate practice
3. Collect experts, papers, and high-signal videos
4. Build the knowledge tree / graph
5. Form and stress-test Spiky POVs against evidence
6. Work a concrete practice-program implication
